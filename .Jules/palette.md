## 2025-02-25 - Synchronized USSD Simulator States and Accessible Logs
**Learning:** When building interactive simulator mockups (like a USSD mobile screen), users have a significantly higher perceived utility and satisfaction when their choices in external configuration panels (like a language switcher) are instantly and visually synchronized in the main visualization terminal. Additionally, updating terminal-like output asynchronously requires using proper `role="log"` with `aria-live="polite"` so screen-reader users can consume diagnostic output sequentially and naturally.
**Action:** Always map mockup elements to centralized application states, use standard localized constants for multilingual lookups, and ensure all dynamic terminal logs have accessible region roles.
