# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-14 - Functional Language Synchronization in Simulators
**Learning:** In interactive simulators (like USSD mockups), synchronizing user selections with both the visual output (the "screen") and a secondary feedback loop (like a Debug Console) significantly increases the "perceived utility" and provides immediate, delightful feedback that a static UI lacks.
**Action:** Always look for secondary feedback opportunities (logs, status bars, headers) to reinforce user actions in simulation components.
