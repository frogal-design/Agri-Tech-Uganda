## 2025-08-08 - Interactive Localization & Simulated States in USSD Mockups
**Learning:** Real-time feedback loops in technical mockups (e.g., USSD mobile screens synchronized with a simulated debug console log) significantly increase perceived utility, engagement, and usability. Additionally, replacing un-focusable grid `div` elements with accessible, semantic `<button>` tags utilizing `aria-pressed` states ensures fully keyboard-navigable and screen-reader-accessible switching mechanisms.
**Action:** Always prefer semantic HTML controls (e.g., `<button>` or `<input>`) for stateful selection in simulated interfaces, bind visual indicators like cursor blinking precisely, use appropriate ARIA labels and `aria-live="polite"` roles for asynchronous output regions like logs, and modularize static configuration maps into localized constants files.
