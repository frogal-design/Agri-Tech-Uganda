# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Interactive Mockup Synchronization
**Learning:** In simulations (like the USSD terminal), synchronizing the visual mockup with centralized application state (e.g., language selection) provides immediate feedback that reinforces the utility of selected settings and creates a more pleasant "live-preview" feel.
**Action:** Use centralized state and lookup maps (e.g., `Record<Language, string>`) to drive localized feedback in UI mockups, ensuring user choices in configuration panels are instantly reflected in the primary visualization.
