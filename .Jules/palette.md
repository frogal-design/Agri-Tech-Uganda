## 2026-07-15 - Interactive Simulator Feedback
**Learning:** In simulations or complex interactive components (e.g., the USSD simulator), synchronizing the visual mockup with centralized application state provides immediate feedback that reinforces the utility of selected settings.
**Action:** Use centralized state and lookup maps (e.g., `Record<Language, string>`) to drive localized feedback in UI mockups, ensuring user choices in configuration panels are instantly reflected in the primary visualization.
