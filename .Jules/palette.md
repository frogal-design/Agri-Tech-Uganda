
## 2024-05-23 - Interactive Semantic Language Selectors
**Learning:** Converting static informational 'div' cards into semantic '<button>' elements with 'aria-pressed' immediately improves accessibility and makes the UI feel "alive" without needing a full redesign. In a Neo-brutalist system, adding 'active:translate-y-0.5' provides the tactile feedback users expect from bold, bordered elements.
**Action:** Always check if "informational" cards in mocks should actually be interactive buttons, and ensure they use proper ARIA states for selection.
