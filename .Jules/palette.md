# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-24 - Interactive USSD Simulator Mockups
**Learning:** In offline-first apps that use simulator mockups (like USSD), keeping the mockup content static while choice controls are visible creates a "broken" mental model. Synchronizing the mockup's terminal text with the user's selection (e.g., language selection updating the header) provides immediate validation and makes the tool useful for localization testing.
**Action:** Always ensure simulator terminals or mockups reflect the state of associated controls to maintain high-fidelity feedback loops.
