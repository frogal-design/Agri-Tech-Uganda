## 2025-08-13 - State-Driven Interactivity and Localized Feedback Loops in Simulator Components
**Learning:** In interactive technical or hardware simulator UI components (like a USSD mobile mockup), static representations feel dull and lack "perceived utility." Providing immediate, multi-dimensional feedback loops (e.g., dynamically translating simulator menu headers/items based on a synchronized state, logging simulated actions into a terminal console using semantic `<div role="log" aria-live="polite">` zones, and allowing actual custom input with typing) drastically improves user delight, testability, and accessibility. Refactoring un-navigable card options into accessible semantic `<button>` elements with exact `aria-pressed` parameters ensures that screen readers can communicate selected states clearly.
**Action:** Always refactor static mock configurations into fully interactive state-driven blocks, back them up with centralized localization tables, make selection cards keyboard focusable, use appropriate live regional ARIA specifications, and synchronize with secondary feedback logs to emphasize functional realism.
