## 2025-03-05 - [USSD Simulator Accessibility & UX Interaction]
**Learning:** Purely visual mockups (like terminal screens and debug logs) can cause screen reader confusion if not properly annotated. Interactive buttons that control simulator states must use `<button>` instead of static `div` elements, utilize `aria-pressed` to signal selection state, and hide purely decorative cursors (like blinking terminal characters) using `aria-hidden="true"`. Furthermore, log-based feedback regions should utilize `role="log"` and `aria-live="polite"` to capture updates dynamically for assistive tech.
**Action:** When designing mockups/simulators, always ensure interactive wrappers are semantic buttons, use appropriate live regions for dynamic console feedback, and exclude purely visual layout markers from the accessibility tree.
