# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Interactive Simulator Feedback Loops
**Learning:** In simulator-style UI, synchronizing a visual mockup with a secondary technical feedback loop (like a Debug Console) reinforces user selections and increases "perceived utility." Users feel more confident in the simulation when they see technical confirmation of their actions.
**Action:** Always pair interactive mockups with status indicators or logs that react in real-time to user state changes to provide immediate, multi-modal feedback.
