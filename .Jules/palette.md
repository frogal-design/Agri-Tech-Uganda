# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Synchronized Mockups and Technical Feedback
**Learning:** In simulations or complex interactive components (e.g., the USSD simulator), synchronizing the visual mockup with centralized application state provides immediate feedback that reinforces the utility of selected settings. Adding secondary feedback loops, like technical logs in a "Debug Console", further increases perceived utility and user delight.
**Action:** Use centralized state and lookup maps (e.g., `Record<Language, string>`) to drive localized feedback in UI mockups, ensuring user choices in configuration panels are instantly reflected in the primary visualization.
