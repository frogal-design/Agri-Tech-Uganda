## 2023-11-01 - Synchronizing Simulator Mockups with State
**Learning:** In technical simulations or complex interactive mockup components (e.g., the USSD simulator), synchronizing the visual representation directly with centralized application state (like selected language and technical logs) provides immediate, tactile feedback. This synchronization increases the user's perceived utility, prevents confusion, and reinforces selected settings. Furthermore, using semantic buttons with `aria-pressed` for option selection ensures full accessibility for screen-reader users, making the mockup usable and comprehensible to everyone.
**Action:** Always link visual-only or technical mockups to functional state handlers. Use lookup maps (`Record<Language, string>`) to drive dynamic localized labels, ensure focus/keyboard access to mockup switches, and preserve accessibility attributes like `aria-pressed`. Avoid interactive elements inside static mockups without functional linkages.
