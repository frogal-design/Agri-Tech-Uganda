
## 2026-06-25 - Interactive Simulator Synchronization
**Learning:** In interactive simulations (like USSD mockups), synchronizing user input (language selection) with multiple output points (mockup header AND debug console logs) significantly increases the "perceived utility" and delight of the micro-UX. Semantic buttons with `aria-pressed` are essential for making these selections accessible.
**Action:** Always look for secondary feedback loops (like technical logs or status headers) to reinforce the impact of a user's selection in simulator-style components.
