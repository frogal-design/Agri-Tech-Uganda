# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Synchronized Technical Feedback in Simulators
**Learning:** In simulator-style interfaces (like the USSD mock), synchronizing user selections with a secondary feedback loop (e.g., a "Debug Console" or technical log) significantly reinforces the user's action and increases the "perceived utility" of the simulation. It provides immediate confirmation that the system has "processed" the selection beyond just a visual state change on the button itself.
**Action:** When building interactive simulations, always ensure that state changes are reflected in both the primary UI and a centralized technical/feedback component to provide a cohesive and robust user experience.
