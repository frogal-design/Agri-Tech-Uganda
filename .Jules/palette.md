# Palette's Journal - Critical UX/Accessibility Learnings

## 2026-06-21 - Synchronized Simulator Feedback
**Learning:** Syncing visual mockups with centralized application state provides immediate, high-fidelity feedback that reinforces the utility of interactive settings (like language selection) in specialized components like USSD simulators.
**Action:** Always link interactive configuration cards to the visual outcome they represent to create a cohesive and delightful "sandbox" experience for the user.
