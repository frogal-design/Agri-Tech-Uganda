
## 2026-06-10 - Interactive USSD Localization
**Learning:** In offline-first agricultural apps, the USSD simulator is a primary trust-building tool. Making it interactive with localized headers (Swahili, Luganda, Luo) provides immediate value to farmers by accurately previewing their actual handset experience. Converting design-heavy 'cards' to semantic buttons is critical for accessibility in Neo-brutalist interfaces where boundaries are stark.
**Action:** Always use semantic <button> tags with aria-pressed for selection cards and provide localized visual feedback within terminal mockups to reflect real-world usage patterns.
