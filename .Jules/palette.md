# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-14 - Interactive Feedback in Simulations
**Learning:** In complex interactive components like simulators, synchronizing the visual mockup with centralized application state and providing secondary feedback (like technical logs) significantly increases perceived utility and user delight. It transforms a static illustration into a functional tool.
**Action:** Always look for opportunities to link configuration panels directly to the primary visualization to provide immediate, multi-sensory feedback (visual + technical logs).
