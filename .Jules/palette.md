# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Synchronized Simulator Feedback Loops
**Learning:** In simulator-style UIs (like the USSD simulator), providing a secondary feedback loop (like a technical "Debug Console") that mirrors user selections significantly increases the "perceived utility" and "tactile" feel of the simulation. Synchronizing these two distinct UI areas (the mockup and the technical logs) via a shared state makes the feature feel robust and professional rather than just a shallow visual mockup.
**Action:** When building interactive mockups or simulators, always look for opportunities to add "system feedback" or "telemetry" that reacts to user input to reinforce the simulation's internal logic and provide immediate, satisfying confirmation of user actions.
