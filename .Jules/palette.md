# Palette's Journal - Critical UX/Accessibility Learnings

## 2023-10-24 - [Interactive Simulator Feedback Loops]
**Learning:** For simulator-style UI (like the USSD simulator), synchronizing secondary feedback loops (like a technical Debug Console) with primary user selections significantly increases the "perceived utility" and delight of the experience. It turns a static mockup into a functional teaching tool.
**Action:** Always look for opportunities to link primary interactions to secondary status indicators or logs to reinforce the state change.
