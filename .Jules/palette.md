## 2026-05-08 - Dynamic USSD Interactive Simulation & Localization
**Learning:** In technical simulators or phone terminal mockups, static visuals can feel broken or low-utility. Synchronizing localized maps and interactive selection triggers (like language switchers) using centralized state immediately increases the user's perceived product utility. Additionally, replacing non-accessible generic divs with fully keyboard-interactive `<button>` tags decorated with `aria-pressed`, `role="log"` and `aria-live="polite"` handles both assistive accessibility and high-fidelity micro-UX simultaneously.
**Action:** Always map interactive lists using `<button>` elements with `aria-pressed` or `aria-selected` attributes instead of plain `div`s with `cursor-pointer`, and tie simulation views dynamically to the shared state for instant feedback.
