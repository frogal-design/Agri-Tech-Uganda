## 2026-06-03 - Proactive Empty States
**Learning:** Empty states without a clear next step create a "dead end" in the user experience. By adding a contextual Call-to-Action (CTA) that mirrors the primary action (e.g., "Post an Ad"), we guide the user toward engagement and reduce friction.
**Action:** Always inspect empty state implementations and ensure they provide a helpful path forward, ideally using the same visual language as the primary action buttons.
