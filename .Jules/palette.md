## 2025-05-15 - Interactive USSD Simulator Localization
**Learning:** Enhancing static mockups with real state-driven interactivity (like language selection) significantly increases the "delight" factor and perceived utility of educational features like USSD simulators. Combining semantic `button` elements with `aria-pressed` and `aria-current="page"` ensures these enhancements are accessible to all users.
**Action:** Always look for opportunities to turn static documentation/previews into interactive, state-driven components using semantic HTML and ARIA attributes.
