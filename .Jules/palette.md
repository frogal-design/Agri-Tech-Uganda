## 2025-07-22 - Interactive USSD Simulator Accessibility and State Sync
**Learning:** Purely visual mockup simulators (like a USSD phone frame) fail screen readers and keyboard users when coded as static clickable div grids. Moving them to semantic, keyboard-navigable `<button>` tags with explicit `aria-pressed` states, and wrapping technical terminal feeds with `role="log"` and `aria-live="polite"` provides immediate, accessible, and delightful feedback that bridges offline workflows with visual fidelity.
**Action:** Always replace mock visual click triggers with semantic interactive elements, utilize state-driven translation lookup maps to dynamically localise visual simulator displays, and expose Technical Console additions to assistive technologies asynchronously using ARIA live regions.
