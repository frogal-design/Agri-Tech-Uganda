## 2023-10-25 - [Interactive Language Selection in USSD Simulator]
**Learning:** Converting static informational cards into interactive semantic buttons improves both discoverability and accessibility. Adding tactile feedback (active transforms) and visual indicators (selection icons/styles) makes the interface feel more responsive and high-quality, especially within a Neo-brutalist design system.
**Action:** Use semantic `<button>` elements with `type="button"`, `aria-pressed`, and tactile CSS transforms for all interactive selection components in future tasks.
