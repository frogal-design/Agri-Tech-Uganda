## 2026-08-05 - Interactive Simulator Accessibility & Micro-UX Synchrony
**Learning:** When developing interactive simulators or mockups (such as the USSD terminal), static decorative wrappers (like divs representing menu items or languages) pose a major accessibility blocker because screen readers cannot interpret them as interactive. Converting these wrappers into semantic `<button>` tags with `aria-pressed` communicates state transitions effectively. Furthermore, pairing these selection updates with interactive live-region log traces (`role="log"`, `aria-live="polite"`) significantly enhances the perceived utility and sensory feedback of the application.
**Action:** Always replace mock visual divs with semantic, key-navigable `<button>` tags with exact ARIA state values. Map their selections dynamically to synchronized output logs using screen-reader polite announcements.
