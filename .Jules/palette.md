# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Synchronized Simulation Feedback
**Learning:** In simulator-style interfaces (like USSD mockups), providing secondary feedback loops—such as technical logs in a "Debug Console" or localized headers—greatly increases the perceived utility and responsiveness of the tool. It validates the user's interaction beyond just a simple button state change.
**Action:** When building interactive simulations, look for secondary UI elements that can be synchronized with state changes to provide immediate, multi-layered feedback.
