# Palette's Journal - Critical UX/Accessibility Learnings

## 2026-06-23 - Interactive Mockups as UX Bridges
**Learning:** In applications targeting low-connectivity users (e.g., rural farmers), interactive simulations of offline interfaces (like USSD) serve as crucial UX bridges. Synchronizing these simulations with the main app state provides immediate visual feedback that reinforces the utility of selected settings (like language).
**Action:** Always look for opportunities to turn static mockups into interactive state-driven components to better demonstrate accessibility features.
