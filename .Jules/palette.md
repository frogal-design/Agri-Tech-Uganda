## 2026-06-07 - Functional and Accessible USSD Localization
**Learning:** In a simulator or mockup interface, static elements become much more intuitive when they respond to user input. Converting non-semantic card-like 'div' elements to functional 'button' elements with 'aria-pressed' attributes significantly improves both accessibility (keyboard navigation) and the overall interactive feel.
**Action:** Always prioritize converting interactive 'card' layouts into semantic buttons and ensure mockups reflect state changes immediately to provide clear user feedback.
