## 2023-10-24 - [Interactive USSD Simulator Accessibility]
**Learning:** For simulator-style UI, converting static mockup elements into semantic buttons with clear accessible states (like `aria-pressed`) and providing real-time technical feedback (via `role='log'`) significantly improves perceived utility and accessibility for users who rely on assistive technologies.
**Action:** Always use centralized state and lookup maps to drive localized feedback in UI mockups, ensuring user choices in configuration panels are instantly reflected in the primary visualization.
