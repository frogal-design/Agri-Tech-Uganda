## 2025-02-14 - USSD Simulator Mockup Synchronization with Centralized Interactive Language Controls
**Learning:** In interactive simulators (such as a USSD mockup for offline accessibility), having static mockup elements can lead to a disorienting user experience. Changing language selectors should immediately drive the visual and text changes inside the terminal mockup, which not only validates that the localized logic is functional but also creates an intuitive micro-interaction loop that feels tactile and alive. Utilizing semantic `<button>` components with `aria-pressed` for the selector cards also resolves keyboard trap and screen reader issues present in clickable `<div>` representations.
**Action:** Always convert static mockup elements to use dynamic state variables synchronized across visual mockup previews and active settings, and use semantic HTML tags with correct state-communicating ARIA attributes (such as `aria-pressed` or `aria-expanded`) for micro-interaction controls.
